# 贪吃蛇 - 进化版

一个增强版的贪吃蛇游戏，支持多种游戏模式、能量系统和成就系统。

## 游戏模式

- **经典模式** - 3条生命，标准速度
- **街机模式** - 1条生命，更快速度
- **禅模式** - 无限生命，慢速放松
- **噩梦模式** - 1条生命，最快速度

## 操作方式

- **方向键** 或 **WASD** - 控制蛇的移动方向
- **空格键** 或 **P** - 暂停/继续游戏
- **触摸滑动** 或 **D-pad** - 移动端支持

## 游戏特色

### 能量系统
- 护盾 - 免疫一次碰撞伤害
- 加速 - 移动速度翻倍，分数翻倍
- 减速 - 放慢移动速度
- 穿墙 - 可以穿越墙壁
- 磁力 - 食物会被吸引向蛇
- 生命 - 增加一条生命

### 等级系统
- 吃食物达到阈值自动升级
- 等级提升会增加移动速度
- 等级>=3时生成障碍物

### 成就系统
- 初尝、暴食、生存100秒、五级跳、十分满
- 千分王、五千分、纯技术、马拉松、速度恶魔

## 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏。

## 技术栈

- HTML5 Canvas
- CSS3 动画
- JavaScript (ES6+)
- Web Audio API
- localStorage 本地存储
