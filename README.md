# Snake Game Evolution

An enhanced snake game with multiple game modes, power-up system, and achievement system.

[中文](#中文) | [English](#english)

---

## English

### Game Modes

- **Classic** - 3 lives, standard speed
- **Arcade** - 1 life, faster speed
- **Zen** - Unlimited lives, slow and relaxing
- **Nightmare** - 1 life, fastest speed

### Controls

- **Arrow Keys** or **WASD** - Control snake direction
- **Space** or **P** - Pause/Resume game
- **Touch Swipe** or **D-pad** - Mobile support

### Features

#### Power-ups
- Shield - Immune to one collision
- Speed - 2x movement speed, 2x score
- Slow - Reduces movement speed
- Ghost - Can pass through walls
- Magnet - Food is attracted to snake
- Life - Adds one life

#### Level System
- Level up automatically when eating food
- Higher levels increase movement speed
- Obstacles spawn at level 3+
- More obstacles at higher levels

#### Achievements
- First Bite, Glutton, Survivor 100s, Level 5, Level 10
- 1000 Points, 5000 Points, Pure Skill, Marathon, Speed Demon

### How to Play

Open `index.html` in a browser to play.

### Tech Stack

- HTML5 Canvas
- CSS3 Animation
- JavaScript (ES6+)
- Web Audio API
- localStorage

## 中文

### 游戏模式

- **经典模式** - 3条生命，标准速度
- **街机模式** - 1条生命，更快速度
- **禅模式** - 无限生命，慢速放松
- **噩梦模式** - 1条生命，最快速度

### 操作方式

- **方向键** 或 **WASD** - 控制蛇的移动方向
- **空格键** 或 **P** - 暂停/继续游戏
- **触摸滑动** 或 **D-pad** - 移动端支持

### 游戏特色

#### 能量系统
- 护盾 - 免疫一次碰撞伤害
- 加速 - 移动速度翻倍，分数翻倍
- 减速 - 放慢移动速度
- 穿墙 - 可以穿越墙壁
- 磁力 - 食物会被吸引向蛇
- 生命 - 增加一条生命

#### 等级系统
- 吃食物达到阈值自动升级
- 等级提升会增加移动速度
- 等级>=3时生成障碍物
- 等级越高障碍物越多

#### 成就系统
- 初尝、暴食、生存100秒、五级跳、十分满
- 千分王、五千分、纯技术、马拉松、速度恶魔

### 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏。

### 技术栈

- HTML5 Canvas
- CSS3 动画
- JavaScript (ES6+)
- Web Audio API
- localStorage 本地存储
